# System-prompt MCP tools

| Tool | Use it for |
| --- | --- |
| `list_prompts` | Prompt files on this server. Optional filters: `service`, `flavor` (`summary`, `system`, `tools`), `provider`, `limit` (1–100, default 25). |
| `get_prompt_suggestion` | One recommendation for an LLM or a task, plus alternatives. |

This skill uses only these two tools.
